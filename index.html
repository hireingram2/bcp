One-time setup — ~5 minutes. You need a free Firebase account so your data syncs across all devices.

1 Create a Firebase project

Go to console.firebase.google.com → Add project → name it bcp-scorecard → skip Analytics → Create.

2 Create a Realtime Database

In your project: Build → Realtime Database → Create Database → choose United States → Start in test mode → Enable.

3 Copy your database URL

You'll see a URL like:
https://bcp-scorecard-xxxxx-default-rtdb.firebaseio.com
Copy it and paste below.
